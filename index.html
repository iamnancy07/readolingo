📚 Add a Book Instructions

📖 How to Add Books by Searching

  1. Enter your Anthropic API key (get one free at console.anthropic.com)
  2. Tap "Save key" — it's stored locally on your device, never shared
  3. Type a book name (e.g., "Harry Potter", "The Hobbit")
  4. Tap "🔎 Search" — Claude finds real published books matching your search
  5. Pick a book from the results to add it to your library

💡 Tips

  • Be specific: "Charlotte's Web by E.B. White" works better than just "Charlotte"
  • Search takes time: Give it up to a minute — Claude is searching for real books
  • API costs: Each search uses your API credits (usually a few cents)
  • Save your key: Clear it when done if you're on a shared device

🔧 Troubleshooting

  • ❌ "Save your API key first" → Paste your key and tap "Save key"
  • ❌ "Key rejected by API" → Your key is invalid or out of credits. Get a new one at console.anthropic.com
  • ❌ "Network error" → Check your internet connection and try again
  • ❌ "No matching books found" → Try a different book name or be more specific (add author name)
  • ⏱️ Search is slow → This is normal! Claude searches the web, which takes up to 60 seconds
  • 🧪 Use "Test key" button → Before searching, tap "Test key" to verify your API key works

🤖 Generate a Book with AI Instructions

✨ How to Generate Books

  1. Enter your Anthropic API key (get one free at console.anthropic.com)
  2. Tap "Save key" — it's stored locally on your device, never shared
  3. Enter the book title and author (e.g., "Matilda" by "Roald Dahl")
  4. Tap "✨ Generate questions" — Claude creates 10+ quiz questions
  5. The book and quiz start automatically

🔒 Privacy & Security

  • Your key is private: Only stored in your browser, never sent anywhere but Anthropic
  • No account needed: Readolingo doesn't store your data or have its own API key
  • Clear key when done: If you're on a shared device, tap "Clear key"

💰 Cost

  • Each generation costs a small amount from your Anthropic account (usually $0.05–$0.25)
  • Anthropic offers free credits to new accounts
  • You only pay for what you use

🔧 Troubleshooting

  • ❌ "Save your API key first" → Paste your key and tap "Save key"
  • ❌ "Key rejected by API" → Your key is invalid or out of credits. Get a new one at console.anthropic.com
  • ❌ "Network error" → Check your internet connection and try again
  • ❌ "Could not generate" → Try a real, well-known book title. Made-up books won't work
  • ⏱️ Generation is slow → This is normal! Claude reads about the book and writes questions, which takes 10–30 seconds
  • 🧪 Test your key first → Use the "Test key" button on the Add Book screen to verify your API key works before generating
